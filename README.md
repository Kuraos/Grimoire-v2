# Grimoire v2

CRM de vida personal con gamificación (hábitos, rachas, XP, tareas, diario, finanzas,
entrenamiento), rehecho para usarse desde Android y el PC.

- **API:** Rust sobre Cloudflare Workers + D1 (plan gratis).
- **App:** React + TypeScript, empaquetada como APK con Capacitor.

Estado: fase 0 (prueba de arquitectura). Ver `docs/tasks/fase-0.md`.
Decisiones en `docs/adr/`. Instrucciones para agentes en `AGENTS.md`.

La v1 de escritorio vive en [Kuraos/Grimoire](https://github.com/Kuraos/Grimoire).
